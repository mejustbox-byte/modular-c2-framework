# Modular C2 Framework

Учебная платформа для исследования управления агентами в полностью изолированных киберучениях.

## Безопасная модель

Проект предназначен для mock-агентов и локальной лаборатории. Listener по умолчанию привязывается к loopback, egress запрещён, команды ограничены тестовым набором, а каждое событие журналируется. Не используйте платформу против систем без письменного разрешения.

## Архитектура

- teamserver API;
- лабораторные listeners;
- mock-agent;
- журнал аудита;
- тестовый UI.
