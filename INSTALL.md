# Installation

Устанавливайте только в отдельной VM или Docker-сети без маршрута к production. Используйте тестовые ключи и синтетические данные. Перед запуском проверьте, что listeners доступны только из лаборатории, а исходящий трафик ограничен.

Инструкции конкретного запуска появятся после принятия архитектуры MVP.
